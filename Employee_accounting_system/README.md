Программа, которая реализует учёт сотрудников и подразделений.
Позволяет хранить данные сотруднико: ФИО, год рождения, должность, образование, оклад
Хранит структуру отделов предприятия: Перечень сотрудников конкретного отдела, а также информацию об руководителе

Особенности:
	Стандарт C++20
	ООП согласно SOLID
	Был реализован собственный шаблонный контейнер = хеш таблица и итераторы для неё
	Многопоточность: Функция, которая ищет всех подчинёных конкретного начальника, реализована в двух вариантах: Стандартная и параллельная обработка данных. Представлены графики их работы. Параллельная обработка имеет преимущество на предприятиях с разветвлённой системой отделов.
	Программа поддерживает сохранение/загрузку состояния из json файла
	Программа покрыта тестами
	Программа реализовано согласно MVC(Model/View/Controller)
	Сборка через CMake
